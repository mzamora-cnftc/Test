# Mi Aplicación Tkinter

Este proyecto es una aplicación de escritorio construida con Tkinter, que proporciona una interfaz gráfica de usuario (GUI) para facilitar la interacción del usuario.

## Estructura del Proyecto

```
mi-app-tkinter
├── src
│   ├── main.py                # Punto de entrada de la aplicación
│   ├── ui
│   │   └── ventana_principal.py # Define la interfaz de usuario principal
│   └── utils
│       └── helpers.py         # Funciones auxiliares para la aplicación
├── requirements.txt           # Dependencias del proyecto
└── README.md                  # Documentación del proyecto
```

## Instalación

1. Clona el repositorio:
   ```
   git clone https://github.com/tu_usuario/mi-app-tkinter.git
   ```
2. Navega al directorio del proyecto:
   ```
   cd mi-app-tkinter
   ```
3. Instala las dependencias:
   ```
   pip install -r requirements.txt
   ```

## Uso

Para ejecutar la aplicación, utiliza el siguiente comando:
```
python src/main.py
```
